# Reverse Rotating Wheel Animation

This is a simple web-based project featuring a rotating wheel animation. The wheel rotates when the mouse enters the area and reverses back to its initial position when the mouse leaves.

### Features:
- **Hover to rotate the wheel forward**
- **Mouse leave to rotate it back**
- **Smooth CSS animations for a fun interactive effect**
